# Lay Groundwork for Offline Caching in Firebase DataConnect

## Overview
✨ This PR lays the groundwork for offline caching within the `firebase-dataconnect` module by implementing mechanisms to store and retrieve complex query results. It defines new Protobuf structures representing data entities and hierarchical paths, along with dehydration and rehydration utilities for query result pruning and grafting.

## Highlights
✨ Key changes:
* **Offline Caching Logic**: Introduced core logic for dehydrating and rehydrating query results, extracting entities from query results and reconstructing full results when needed.
* **New Protobuf Definitions**: Added new Protobuf messages in `sdk.proto` including `FieldOrListIndex`, `EntityPath`, `Entity`, `EntityList`, `EntityOrEntityList`, and `QueryResult`.
* **Data Manipulation Utilities**: Implemented `ProtoGraft` for inserting values into Protobuf `Struct`s/`ListValue`s and `ProtoPrune` for selective descendant removal.
* **Path Handling Enhancements**: Added utility functions and comparators for `DataConnectPath` and `DataConnectPathSegment`.
