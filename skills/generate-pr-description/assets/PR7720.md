# Add SQLite Database Layer for Offline Caching in Firebase DataConnect

## Overview
✨ This PR adds a SQLite database layer to `firebase-dataconnect` that manages cached query results and associated entities, complete with schema migration, secure database opening, and utility functions for thread-safe database interaction.

## Highlights
✨ Key changes:
* **New SQLite Database Logic**: Introduced SQLite database implementation for offline caching with dedicated database management and schema migration classes.
* **Thread-Safe Operations**: `DataConnectCacheDatabase` uses coroutines and single-threaded dispatchers to manage write transactions safely and prevent `SQLITE_BUSY` errors.
* **Robust Schema Management**: `DataConnectCacheDatabaseMigrator` handles initialization and schema migrations, managing `application_id` and `user_version` pragmas.
* **Enhanced SQLite Utilities**: Added extension functions for `SQLiteDatabase` (`SQLiteDatabaseExts`) and `SQLiteStatementBuilder` for simplified queries and parameterization.
* **Utility Classes**: Added `ImmutableByteArray`, `SemanticVersion`, and `StringUtil` for binary, versioning, and string operations.
