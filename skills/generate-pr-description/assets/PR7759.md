# Enable Offline Caching in Firebase DataConnect

## Overview
✨ This PR wires up the offline caching mechanism in `firebase-dataconnect`, integrating the SQLite cache database into the main `executeQuery` flow. It handles cache lookups, insertions, and configuration based on `DataConnectSettings`, while updating Proto definitions to support GraphQL extensions for cache metadata.

## Highlights
✨ Key changes:
* **Cache Integration**: `executeQuery` now checks the local SQLite cache before making a network request, returning valid cached results immediately.
* **Cache Population**: Successful network responses are inserted into the SQLite cache.
* **Configuration**: Database name is deterministically calculated based on connector configuration to ensure isolation.
* **Proto Updates**: Added `GraphqlResponseExtensions` to `ExecuteQueryResponse` proto to carry cache-related metadata (`max_age`, `entity_id`).
